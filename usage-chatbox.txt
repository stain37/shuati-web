============================================================
  刷题站 · 从本机 Chatbox 导入 AI 配置 / 知识库
============================================================

  不带参数 = 导入 API Key + 全部知识库（文件多，可能好几分钟）
  只要 API Key：   从Chatbox导入.bat --key
  先看看有哪些库： 从Chatbox导入.bat --list
  只导入某个库：   从Chatbox导入.bat --kb 7   （7 = 西综）
  合成一个总库：   从Chatbox导入.bat --all
  跳过慢的 PDF：   从Chatbox导入.bat --skip-pdf
  只读每个 PDF 前 30 页：--pdf-pages 30

  结果：
   · AI配置.js   ← Chatbox 里的 Key / 模型（网页会自动读，含明文 Key，别外传）
   · 知识库.js   ← 重新解析出来的资料（刷新网页就自动挂载）
============================================================

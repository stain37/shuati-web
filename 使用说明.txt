刷题站 · 使用说明

这是一个纯静态的刷题网站：选择题目当场判分、错题自动进错题本、能模拟考、能用 AI 写解析，
还能让 AI 先翻自带的资料库再回答。不用安装、不用联网也能刷题。

  这份说明是给「拿到这个文件夹的人」看的。原作者的其他文档（README.md、AI知识库说明.md、
  更新说明.md）都还在，想深挖再看。

  这一份是「在线版」：原作者自己的 API 配置（AI配置.js）和内置模考卷都已移除，
  包里没有任何密钥；想加题就用网页上的「导入题库」，或按第六节导入数据备份。


■ 一、先打开它（两分钟）

方式 1（最省事）：双击 index.html —— Chrome / Edge 都行，直接就能刷题。
　· 作答记录存在这台电脑的浏览器里（换浏览器、清缓存会丢，重要数据请导出备份，见第六节）。

方式 2（推荐）：双击 本地服务器.bat —— 会用 http://localhost:5173/ 打开。
　· 好处：可以「安装到桌面/主屏」离线使用、自己导入的知识库能存进 IndexedDB（容量大得多）、
　　中文输入法更顺、连本机 Ollama 也更稳。
　· 要电脑装了 Python（python.org 下载时记得勾 "Add python.exe to PATH"）。
　· 黑窗口别关，关掉就等于关掉服务器。

　· 没装 Python 也没关系：现在这个 .bat 会自动改成直接打开 index.html，功能一样不少。

方式 3（手机也能刷）：双击 手机访问.bat —— 手机连同一个 Wi-Fi，用浏览器打开窗口里显示的地址
（形如 http://192.168.x.x:8080/）就能刷题，和你电脑上看到的是同一套题库。
　· 不用上传、不用注册，纯局域网；电脑要开着，黑窗口别关。
　· 这种 http 地址在手机浏览器里不能「装成 App」、不能离线，其它功能（资料库、AI、错题本）都正常。
　· 想手机上长期用、能离线、有图标 → 看第五节。

方式 4（电脑上像软件一样）：双击 像App一样打开.bat —— 用 Edge / Chrome 开一个没有地址栏、
没有标签页的窗口，看起来就是个软件；找不到就用默认浏览器打开。


■ 操作小抄（顺手一下就会）

首页从上到下：统计看板（上面那些数字都能点）→ 继续刷题（上次刷到哪一题，点一下接着刷）→ 两排按钮
（上面一行：新建/导入题库、今日复习、随机抽 30 题；下面一行：错题本、收藏、搜索、学习统计、快捷键、新建分类、批量管理题库）
→ 目录导航 + 我的题库 → 数据备份。点题库名、卡片或「开始」进答题页。

分类目录（首页「我的题库」那一块）：
　· 新建目录：点「＋ 新建目录」，目录里还能再套子目录；点目录名进出，右边的箭头折叠或展开。
　· 把题库放进去：直接把卡片拖进目录；手机上不方便拖，就在卡片上点「移到…」选一个目录。目录之间也能互相拖。
　· 目录名后面写着「几套题库」；顶上的「目录导航」是一排按钮，点一下直接跳到那个目录。
　· 想一眼看全整棵树，点「展开 / 收起目录树」——树里的目录点一下就直接跳进去（含它下面的子目录），进去后上面会有「↑ 上一级」。
　· 题多的时候可以切 ▦ 卡片 / ☰ 列表：「全部题库」那一行右边有个切换，列表模式一行一个题库（名称 + 题数 + 正确率 + 「开始 / 错题 / 移动」），一屏能看十几个；你选的模式会记住。
　· 搜索框写着「搜索目录 / 题库名」：按目录名也能搜，命中时会把该目录下所有层级的题库一起列出来。
　· 目录只是「归属」，不会动题库本身；删目录只把里面的东西挪到上一级，题库一道题都不会少。

答题页：
　· 选选项：鼠标点，或直接敲字母 A–H / 数字 1–8；多选先把选项都选上，再按 Enter 提交。
　· 翻题：← →；底部中间的按钮显示「第几题 / 共几题」，点它是答题卡。
　· 答题卡里能筛「全部 / 做错 / 没做」，点题号直接跳；题号右上角黄点＝你自己标的记号。
　· S 收藏当前题，K 开答题卡（选项字母被 A–H 占着，所以收藏和答题卡特意用 S / K），? 打开快捷键小抄（再按一次收起，里面按「答题 / 找题 / 界面」分了三组），Esc 关掉弹窗。
　· 判完分会自动把解析滚到眼前（不想自动跳下一题，去设置里关掉「答对自动下一题」）；
　解析下面还多了一个「下一题 →」按钮，答完不用再滚回底部（最后一题会变灰）。
　· 手机上：左滑 = 下一题，右滑 = 上一题；长按题干会弹出「复制题干 / AI 解析 / 收藏 / 关闭」小菜单。
　判分那一刻，选中的选项会闪一下（答错还会轻微震一下），答错会顺手告诉你「已记入错题本」。

搜索与错题本：
　· 搜索页按 / 直接跳到搜索框（在哪个页面按 / 都能用，首页会直接聚焦首页那个搜索框）；搜索框吸在顶部，翻长列表不用回头。
　· 搜索会记住上次搜的词和范围（全部 / 错题 / 收藏 / 待复习 / 没做过的），下次进来直接带出来；
　如果命中的是选项或解析，行头会有个橙色「命中：选项」标签，题干下面多一行原文片段并高亮 —— 不用展开就能看。
　· 错题本上面还能再筛：按考点（只列当前这些错题里真有的考点，带题数）、找词（题干 / 选项 / 解析里搜，
　空格分开多个词，命中的地方会高亮）、错次 ≥ N；这几个和原来的题库、只看没做对的、只看今天到期都能叠着用。
　· 错题本 / 收藏页的「勾选、批量、套卷、导出」收在「批量操作与导出」折叠条里，点开才展开
　（折叠条上写着已经勾了几题）。
　· 不想再练这道错题了？展开它，操作行里有「✗ 剔除错题」：只把「错题 / 待复习」标记去掉，
　作答次数、正确率、收藏、你自己写的解析全留着（下次答错还会自己回来）。误点了 5 秒内能撤销。
　· 批量那块现在能一次办好几种事：✗ 剔除错题（保留记录）、✓ 标记已掌握（做对过就不再排复习）、
　+ 加考点标签（输一个考点，给勾选的题一起贴上，输入框会提示你词表里已有的考点）。
　前两个只有错题本里才有 —— 收藏页只给「取消收藏」和「加考点标签」。
　· 手滑点错不怕：取消收藏、从错题本移除、剔除错题、加标签之后，气泡上都有「撤销」，5 秒内点一下就回来。

首页：
　· 顶上那排数字（题库 / 道题 / 已答 / 正确率 / 错题 / 收藏 / 待复习）都是按钮：点错题进错题本、
　点收藏进收藏、点待复习直接开始今日复习、其余点进学习统计；待复习是 0 的时候那块会变淡。
　· 按钮分两组：上面一行是「＋ 新建 / 导入题库」「今日复习」「随机抽 30 题」，
　下面一行是错题本 / 收藏 / 搜索 / 学习统计 / 快捷键 / 新建分类 / 批量管理题库。

学习统计页：
　· 上面六个数字块有五个能点：累计做题 / 累计正确率 / 今日已答 / 连续天数 点了滚到对应小节，
　待复习点了直接开始今日复习（今天没有该复习的题时那块变淡、点不动）。
　· 「近 14 天」的柱子可以点：点哪根，右边就显示那天的作答详情（做了几题、对几题）。
　· 「各题库正确率」和「错得最多的题」都是整行可点：点题库行进题库接着刷，点错题行直接跳到那道题。

AI 变式题（让 AI 照这道题出几道新题）：
　· 答题页、以及「错题本 / 收藏」里展开的卡片上，都有「AI 变式题」按钮 —— 点开是就地展开的面板（不弹新窗口）。
　（要先配 AI，看第二节；没配的话面板里会直接告诉你去哪配。）
　· 面板上半是这道题的只读预览；中间挑命题方向（9 个，可多选）、要几道（3 / 5 / 8），
　需要的话勾上资料库（用你导入的资料当命题依据）；下面还能自己写一句话，比如「题目要更长、选项之间互相干扰」。
　· 生成完是一张张卡片：正确选项标绿、带解析；中途能「停止」，不满意能「重新生成」、想换地方问能「复制提问」，
　也能点「改答案」自己订正。
　· 每张卡片会算出库里最像的 3 道老题（本地算的，不花 AI）：点开看相似度百分比，
　点「并排对比」把两边摊开、共有的字词高亮 —— 一眼看出 AI 是不是只换了层皮。
　· 满意就点「存成新题库」：变式题进一个自建题库，首页立刻能看到，云同步也会带上。

做完一套题的小庆祝：
　· 交完卷、或把「一套卷子」的最后一题做完，会撒一把彩带 + 一个 🎺 和一句按分数分档的话。
　· 同一套题只庆祝一次（点「再答一次」或「再用这套题考一次」会重新算）。
　· 不想要：设置里关掉「做完一套题放彩带」；普通题库也想庆祝，就打开「普通题库刷完也放彩带」（默认是关的）。

动效（系统里开了「减少动态效果」就都不播）：
　· 答完一题不再整页闪一下；选项选中会弹一下、答错轻轻抖一下；错题本 / 收藏的卡片从上往下错开出现；
　统计页的柱子从下往上逐根长出来；深浅色切换时颜色有过渡。

外观与手机：
　· 顶栏的 ◐ 一键切换：跟随系统 → 浅色 → 深色（设置里也能选）；设置里还能调字号。
　· 主题色（新）：设置里「字号」下面多了主题色——蓝（默认）/ 靛 / 青 / 紫。选完整个站点跟着变（按钮、选中态、底部导航、首页那张大卡片、进度条），刷新后还记得；不喜欢就选回蓝。
　· 导航都在底部一条上（新）：首页 · 错题 · 收藏 · 搜索 · AI · 同步 · 设置，哪个页面都在，正在看的那页会亮起来。
　· 答题时底部是两行：上面那行还是这些入口，下面那行是「上一题 / 答题卡 / 下一题」——不用退回顶部也能换页。
　· 顶栏只剩「标题 + 进度 + ◐（＋资料库的「文件」）」了，不再一换页就有一排按钮冒出来/缩回去。
　· 底部导航贴着屏幕底部也不会被 iPhone 的横条挡住。

设置弹窗（新）：
　· 打开就是常用那几样：外观、字号、四个开关、「复习曲线」（复习节奏）—— 手机上一屏就能看完。
　· 更细的参数（首次/第二次间隔、易度、每日上限…）、「普通题库刷完也庆祝」、快捷键说明，都收在
　　「高级：复习参数 · 庆祝范围 · 快捷键」折叠条里，点一下才展开。
　· 「复习曲线」＝节奏档位：松＝长期记忆、标准＝经典 / Anki、勤快＝考前冲刺；选完下面会写一句
　　「答对后的间隔：1 → 3 → 8 → 20 → 50 → … 天」，不满意再展开高级逐项改（改一项会自动变「自定义」）。
　· 触屏（手机 / 平板）上不再显示答题页那行快捷键提示 —— 没键盘用不上，留着占地方。


■ 二、配 AI（想用「AI 解析」才需要，不配也能刷题）

AI 与知识库这个页面（新）分成四个标签页，点上面的圆角按钮切换：
　① AI 服务（填接口地址 / 模型 / Key）、② 知识库（导入、勾选资料）、
　③ 试检索（只用关键词试一下资料能不能被找到，不花 token）、④ 怎么用（六条上手说明）。
　· 切标签是就地切换：填了一半的配置不会丢、页面也不会重刷；刷新后回到①。

配法三条，挑一条就行：

· ① 在网页里填一次（最简单，1 分钟）
1. 打开站点 → 点「AI 与知识库」（或题目下方的「AI 解析」）
2. ① AI 服务：下拉选一个，常用的有
　　　· DeepSeek 云端 API　　接口地址 https://api.deepseek.com/v1　模型 deepseek-flash 或 deepseek-v4-pro
　　　· Kimi / Moonshot　　 https://api.moonshot.cn/v1　　　　　　模型 moonshot-v1-8k
　　　· 本地 Ollama（免费、离线）http://127.0.0.1:11434/v1　　　模型 qwen2.5:7b，API Key 留空
　　　· 本地 LM Studio　　　 http://127.0.0.1:1234/v1　　　　　　模型填它显示的模型名
　　　· 自定义　　　　　　　任何「OpenAI 兼容」的接口都行，地址一般以 /v1 结尾
3. 把 API Key 粘进「API Key」框（本地模型不用填）
4. 模型：点「模型」框会列出这个服务的常用名字（选了 DeepSeek 就有 deepseek-flash / deepseek-v4-pro
　 可选）；想拉服务端真实可用的全部名字，点旁边的「拉取模型列表」（要先填好 Key）。
5. 点「测试连接」→ 显示 OK 就能用了。
配置只存在这台电脑的浏览器里，不会上传到任何地方。
（注意：同一个浏览器里所有 file:// 页面共用一份存储，所以在同一台电脑上打开别人分享的副本时，
　可能看到你自己先前填过的配置 —— 那是本机浏览器里的，不是文件里的。点①里的「清空本机配置」
　可一键清掉；换电脑或开无痕窗口打开就是空的。见第六节 FAQ。）

· ② 用预置文件（多台电脑、想省事）
把 AI配置.示例.js 复制一份、改名成 AI配置.js（去掉「.示例」），用记事本打开，
把 base / model / key 改成你自己的，存好。以后网页一打开就自动填好。
（文件里是明文 Key，别再把它传给别人。）

· ③ 你也在用 Chatbox → 双击「从Chatbox导入.bat」
它会读 Chatbox 里的 API Key / 模型写成 AI配置.js，并把 Chatbox 的每个知识库都搬成
一排可单独勾选的标签。（没装 Chatbox 就跳过这条，站点不会因此出问题。）

· 完全免费的离线方案
装 Ollama（ollama.com）→ 命令行执行 `ollama pull qwen2.5:7b` →
再设一个环境变量 OLLAMA_ORIGINS=* （否则网页连不上它，详见 AI知识库说明.md）。
■ AI 写出来长什么样，由你说了算
· 默认不套任何固定格式：你在提问框写什么，它就写什么。
· 想要每道题固定输出「答案 / 为什么 / 其它选项 / 易错点」，在配置页勾上「套用……模板」。
· 想长期固定要求（比如「用大一水平讲」「只讲错的那个选项」），写在「额外要求」里，会一直生效
　（和模板是叠加的，不是替换）。
· 想让它用颜色/高亮标重点：说一句「正确项标绿、错误项标红、关键句高亮」就行 ——
　模型写 ==高亮== 或 <font color="red">红字</font>，页面上会真的显示成黄色高亮和红/绿字
　（颜色只认颜色名或 #hex，写别的当普通文字显示，不会执行任何代码）。

■ 生成的时候可以放心干别的
· 点完「生成解析」，接着敲键盘不会把生成打断（在输入框里打字更不会误触发快捷键）。
· 生成期间答题快捷键会暂时让路（A–H / Enter / ← → / S / K 都不响应）；想边生成边答题，
　先点面板上的「停止」。
· 生成中去翻别的题、回首页，请求会自动停掉，不会在后台白花钱。
· 翻回原来那道题，之前生成的内容还在（3 分钟内都还记得）。
· 追问的时候，上一轮问答会收进「之前的 N 轮追问（点开看）」折叠块里，面板上只留最新那次回答；
　想从头开始，点面板上的「清空对话」。
· 生成的时候，另一个标签页改了数据（比如你在别的窗口作答）也不会把面板冲掉：数据会先收进内存，
　等你关掉面板、翻页时再一起重画。


■ 给题打「考点」标签，让它告诉你哪儿最弱（新）
  · 每道题下面有一行标签：点「＋ 标签」就地打上考点（如"慢阻肺"），Enter 加一条、可以连着加，
    Esc 只收起输入框；点标签上的 × 删掉。打过的词自动进词表，下次点建议就加上了。
  · 统计页最下面多了「按考点」：每个考点的题数/已答/正确率/错次，按正确率从低到高排
    （答得少于 5 题的标"样本不足"）；点考点名直接跳到搜索页并填好；上面有「刷最弱的 3 个考点」。
  · 主要是让 AI 贴（要先配好 AI）：先把词表准备好（下一节，自己批量导入最省事；也能点「让 AI 起一份词表」
    让它从你答过的题里提词，不合适的点掉），再点「给没标签的题贴标签」—— AI 读每道题的题干和选项，
    只从你的词表里挑标签贴上去；分批跑、随时能停，已经贴好的留着。统计页「按考点」汇总的就是这些标签。

■ 考点词表从哪来：自己批量导入（新）

  · 统计页最下面「按考点」卡片里（下方的词表卡片里也有）点「批量导入考点词」：弹出一个粘贴框，
    一行一个，写「名称」或「名称：说明」都行，例如：
        慢阻肺：持续气流受限、FEV1/FVC<70%
        心力衰竭
        3. 酸碱平衡：血气分析判断失代偿
    序号（1.）、项目符号（- •）、首尾引号会自动去掉，重名的跳过；导入完告诉你「导入 N 个（跳过 M 个）」。
    也能点「选择文件」直接读一个 .txt / .csv。
  · 词表只存在本机（跟着「导出全部数据」的备份走，也能跟云同步），随时能再改。

■ 学情诊断（周报）：让 AI 说说这段时间学得怎么样（新）
  · 统计页最下面多了「学情诊断（周报）」，点开就是这一块；也可以地址栏敲 #/report。
  · 选时间窗（7 / 14 / 30 天）点「生成」：AI 按你这段时间的记录写一份诊断 —— 做得怎么样、最弱的是哪几个
    考点、错因大概是什么、下周建议干什么。想换个角度（比如"只讲错因"）在输入框补一句再点「换个说法再问」。
  · 它只把摘要发给模型（做题数、正确率、每天走势、按考点的正确率、错得最多的 20 道题的短题干、复习排期），
    不会把整本错题集原样发出去；报告存在本机，只留最近 20 份，能重新打开、也能删。
  · 只有手点才会跑：做题太少或今天已经生成过，会先问一句再发请求（省钱）；生成中能「停止」，
    30 秒没响应自己收手。报告能「复制」成 Markdown、也能「导出 .md」。没配 AI 也能看这一块，它会提示去配。

■ 换个模型：拉取完直接从下拉里挑（新）

  「设置 → AI」里点「拉取模型列表」，接口真的返回模型之后，下面会多出一块「可选的模型」：
  拉到的模型全在这个下拉里（以前要自己点进输入框、按方向键才看得见候选）。选一条就自动填进
  模型框、写进配置；模型多的时候最上面有过滤框，敲两个字就筛出来。这份清单跟着配置一起存下
  来，下次打开还在。

■ 云同步：考点标签也能一起同步（新）

  「设置 → 同步」的「同步内容选择」里多了一项「考点标签」（连考点词表），默认勾着。
  勾上之后，电脑上贴的标签和词表会跟着答案记录进云盘，手机拉一次就有；两边都打过标签的题
  以本机为准，本机没有的补进来，删掉的不会被复活。（以前那项「考纲考点清单」连同功能一起删了。）

■ 三、自带的资料库（172 万字，已经打包在文件夹里）

资料库  ｜  文件数  ｜  正文字数
外科精编版（完整版）  ｜  43 篇  ｜  约 17 万字
内科精编版（完整版）  ｜  73 篇  ｜  约 67 万字
生化精编版（完整版）  ｜  34 篇  ｜  约 29 万字
生理精编版（完整版）  ｜  37 篇  ｜  约 40 万字
病理精编版（完整版）  ｜  23 篇  ｜  约 18 万字

· 这 5 个库是用脚本直接从原始 PDF 抽出来的（整本入库，厚书按书签再切成小节），
　不是「一个 PDF 只取开头几万字」，所以生僻章节也能检索到；详见《AI知识库说明.md》。

· 它们在 知识库.js 这个文件里（网站打开时自动挂载），在「AI 与知识库」页就能看到。
· 做题时点「AI 解析」，它会先从这些资料里检索出最相关的几段，再让模型照着写解析。
· 想让 AI 只用其中几个库：AI 面板顶部那排标签，点一下亮 / 再点灭，可以多选；
　第一个「总库 · 全部」= 一键全选；一个都不选就纯靠模型自己的知识回答。
· 检索几段合适：默认 4 段够用（面板上有实时提示，调大「检索片段数」记得把「资料上限」也调大）。

· 加自己的资料
1. 把 .pdf / .docx / .txt / .md 丢进站点目录的 资料\ 文件夹
2. 双击 转知识库.bat（需要 Python；读 PDF 还要先 `pip install pypdf`）
3. 回到网页按 Ctrl+F5 刷新 —— 新资料库就出现了

· 关于容量
文件库（知识库.js）不占浏览器空间，跟着文件夹走就行。
自己在②里粘贴/导入的资料才会存进浏览器：用「本地服务器.bat」打开时存 IndexedDB（容量大），
双击 index.html（file://）时只能退回 localStorage（约 5 MB），大资料请走 资料\ + 转知识库.bat 这条路。
· 自己导入的资料库会跟着云同步走（和作答记录一样）：电脑上导进去的，手机同步一下就有；手机上删掉的，
　电脑同步一下也跟着删（见第六节）。自带的那 5 个「精编版」库不用同步 —— 它们就在站点文件里，两边都有。


■ 四、搬走你的记录（换电脑/重装前必看）

作答记录、错题本、收藏、自定义解析、自己导入的题库都存在这台电脑的浏览器里。
搬家办法：首页拉到最下面 →「数据备份」→「导出全部数据」得到一个 .json 文件；
在新电脑的站点里点「导入数据（恢复）」选这个文件即可。
备份里含作答、错题、收藏、解析、自己导入的题库和知识库正文；
知识库.js 里的文件库不打包（它本身就在文件夹里，跟着走就行）。

更省事的办法：让数据自己写进本机文件。首页「数据备份」卡里点「选择文件」，挑一个 .json 作为存档
（建议叫「刷题站-题库备份.json」）；以后每次改动都会自动写进这个文件，不用记着点导出
（Chrome / Edge 支持；同排还有「立即写一次 / 打开别的文件 / 断开」，边上会显示「上次写入 时间」）。
换电脑时把这个 .json 拷过去，用「打开题库文件」或「导入数据（恢复）」读回来即可。


■ 五、做成手机 App / 放到网上

三条路，按需要挑一条：

① 只在同一个 Wi-Fi 里用（最快，不上传任何东西）
双击 手机访问.bat → 手机浏览器打开窗口里显示的地址（形如 http://192.168.x.x:8080/）。
　· 电脑要开着、黑窗口别关；手机和电脑连同一个 Wi-Fi。
　· 资料库、AI 解析、错题本都能用；但 http 不是安全环境，不能装成 App、不能离线。

② 放到网上，手机「安装」成 App（想长期用就这条）
把整个文件夹上传到任意静态托管即可（无需构建、无后端）：Cloudflare Pages、GitHub Pages、
Netlify、Vercel，网页上拖拽上传就行。然后手机浏览器打开那个网址，会提示
「添加到主屏幕 / 安装应用」—— 装完就是 App 的样子：有自己的图标、全屏无地址栏、
断网也能刷题（自带的资料库也在离线缓存里，见下）。
　· 具体步骤（Cloudflare Pages / Netlify Drop / GitHub Pages 三条路、手机安装、数据搬家、不传资料库的瘦身版）另见 上传步骤.md。
　· 手机上的 AI 解析：云端 API（DeepSeek / Kimi）没问题；电脑上的 Ollama 手机访问不到。
　· 上传前想清楚两件事：知识库.js 是资料正文（版权），AI配置.js 里有明文 Key，别传上去。

③ 想要真的 .apk 安装包
把②的网址丢进 https://www.pwabuilder.com/ ，它会在云端打好 Android 包给你下载
（不用装 Android Studio、不用 JDK）。本站已经具备它要的三样：https、manifest.json、service worker。

手机 App 里还能用自带资料库吗？
能，而且离线也能搜。知识库.js 就是站点文件的一部分，装成 App 后它同样在这份离线缓存里，
检索段落、AI 照资料写解析、知识库标签勾选，全都和电脑上一模一样；
只有①那种局域网方式才是每次找电脑要数据，电脑一关就没了。


■ 六、电脑 ↔ 手机 共用一份记录（云同步）

答题记录、错题、笔记默认只存在各自的浏览器里。想两边共用一份，用一个私有仓库当云盘（纯静态站点，不用自己搭服务器）。
云盘服务商二选一，在同步页第一格「服务商」里切换：码云 Gitee（推荐，国内约 0.2 秒/次）/ GitHub（约 1.2–1.7 秒/次）。

1. 码云：gitee.com 登录 → 设置 → 安全设置 → 私人令牌 → 生成新令牌（勾 projects）→ 复制；
　 右上角 + → 新建仓库（名字如 shuati-sync，必须选「私有」）。
   GitHub：Settings → Developer settings → Personal access tokens (classic) → 勾 repo → 生成，复制 ghp_...
2. 电脑上：顶栏「云同步」→ 服务商选码云 Gitee（GitHub 也行）→ 填 仓库属主 / 仓库名 / token
　 （码云分支填 master、GitHub 填 main）→「测试连接」→「立即同步」→ 勾上「自动同步」。
3. 手机上：打开同一个网址 → 顶栏「云同步」→ 填完全一样的内容 → 立即同步 → 勾上「自动同步」。

会同步：作答记录、错题、收藏、笔记、自定义解析、套卷、背诵 SRS、自建题库、自己导入的资料库（知识库）、AI 配置（含 Key）。
不同步：站点外观设置、自带的 5 个「精编版」库（它们在站点文件里，本来就两边都有）。
删除也会同步（删掉的题、删掉的资料库，不会被另一台设备「复活」）。
顶栏那个「同步」小按钮：点一下 = 立刻同步一次；Shift+点（或右键、长按）= 打开云同步设置页。
不想用云盘：首页「数据备份 → 导出全部数据」，把 json 发到手机导入（两边的记录都保留）。
详见《使用说明.md》第六节（含 token 安全提醒）。


■ 七、常见问题

Q：打开是白屏 / 排版乱了？
A：按一次 Ctrl + F5 强制刷新。还不行就换个浏览器（Edge / Chrome），或确认文件夹是完整解压出来的。

Q：双击 .bat 黑窗口一闪就没了？
A：说明没装 Python。直接用方式 1 双击 index.html 就行；或者装 Python 时勾上 Add to PATH。

Q：「AI 解析」报错连不上？
A：①先用「测试连接」看配置对不对；②本地模型要确认服务在跑、并设了 OLLAMA_ORIGINS=*；
③云端要确认 Key 有余额、模型名没写错（DeepSeek 现在只有 deepseek-flash 和 deepseek-v4-pro；老的 deepseek-chat / deepseek-reasoner 官方已下线）。

Q：AI 报「额度 / 余额用完了（HTTP 429）」或者「问得太密了（HTTP 429）」？
A：两个 429 不是一回事。拉模型列表能通、一生成就报「额度 / 余额用完了」，是服务商那边的额度 / 余额
　用光了（去 Kimi（Moonshot）/ DeepSeek 的控制台看账户页）—— 换便宜的小模型（如 moonshot-v1-8k）
　或本机 Ollama 都能先顶着。写着「问得太密了」才是限速：等 30–60 秒再点，或者把设置里的
　「检索片段数」「资料上限」调小、把「让模型把捞回来的段落重排」关掉，一次问得轻一点。
　两种报错后面都会跟一句服务商原话（例如 [exceeded_current_quota_error] Exceeded current quota…），照着它去查最准。

Q：换了新模型，报「这个模型只接受 temperature=1」或者「模型名不存在」？
A：有些新模型（推理模型，如 kimi-k3）只收 temperature=1，别的值会回 400（原话里带一句
　invalid temperature: only 1 is allowed for this model）。站点会自己按 1 重试一次，成了就不打扰你，
　只在状态行写一句「这个模型只收 temperature=1，已经自动按 1 走」；它还会把这个模型的脾气记在本机
　配置里，以后用这个模型一上来就按 1 走。想更清爽，把设置里的「温度」直接改成 1。真要是模型名写错
　（原话里是 model not found 这类），才会说「模型名不存在」——那时点「拉取模型列表」从里面挑一个真名。

Q：我一打开副本，AI 配置里怎么还显示我自己填过的 Key？
A：站点文件里没有你的 Key（这一份已经把原作者的 AI配置.js 删掉了）。你看到的是这台电脑浏览器里
　存过的那份配置：同一个浏览器里，所有用 file:// 打开的页面共用一份存储，所以会把你自己在别的
　刷题站页面填过的配置带过来。核对办法：① 点配置页的「清空本机配置」按钮，当场就没了；
　② 换一台电脑或开无痕窗口打开，是空的；③ 在文件夹里搜 "sk-"，这一份搜不到。

Q：可以删掉哪些文件？
A：以下都能删，删了站点照常跑：
　· chatbox-import.py / 从Chatbox导入.bat / usage-chatbox.txt（不用 Chatbox 时）
　· make-kb.py / 转知识库.bat / 资料\（不想自己加资料时）
　· 更新说明.md（原作者的开发记录）、usage-*.txt
　· 知识库.js（不要自带资料库时，删了 AI 就只靠模型自己回答）
　不能删：index.html、app.js、collection.js、exam.js、kb.js、ai.js、sync.js、style.css、sw.js、manifest.json、icons/、banks/

Q：能放到网上给别人用吗？
A：可以，整个文件夹丢 GitHub Pages / Vercel / Netlify 或任意静态空间即可（无需构建、无后端）。
　但两点注意：① 知识库.js 是资料正文，公开前先想清楚版权；② 每个访客的记录存在各自浏览器里，不互通。

Q：手机上能用吗？
A：能。想立刻试：双击 手机访问.bat，手机连同一 Wi-Fi 打开它显示的地址。
　想长期用、能离线、有图标：按第五节②放到网上，再用手机「安装应用 / 添加到主屏幕」。

Q：电脑上刷的记录，怎么弄到手机上？
A：按第六节配一次「云同步」（码云 Gitee 或 GitHub 私有仓库当云盘），之后两边自动互通，连 AI 配置、
　自己导入的资料库一起带过去。不想折腾云盘：首页「数据备份 → 导出全部数据」把 json 发到手机导入。

Q：顶栏那个「同步」小按钮点了没反应？
A：它就是「立即同步一次」：点一下显示「同步中」，完了闪一下「已同步」。显示「同步!」（带感叹号）
　说明上次失败，点开同步页看红字（多半是 token 过期或没网）。想打开同步设置页：Shift+点、右键或长按。

Q：AI 正在写解析，我点「收藏」会不会把它打断？
A：不会（2026-10 已修）。收藏现在只把五角星就地点亮，不再重画整个页面，生成流不受影响。
　2026-10-17 又修了一层：就算页面真的重画了（点选项判题、点筛选标签、展开/收起错题本的一行、
　别的标签页改了数据触发刷新……），正在写的解析也会自己挂回新面板，连已经写出来的字和还没发出去的提问一起恢复；
　换成别的题时会先把面板收起来（那属于上一题），翻回来内容还在。想中途停下就点「停止」。

Q：云同步报错（测试连接不过 / 401 / 409 / 400）？
A：先点「测试连接」：① 401/403 = token 不对或没权限（码云勾 projects、GitHub 勾 repo），或仓库名/属主写错；
　② 连不上 = 换网络；用 GitHub 国内可能要开代理，或者把服务商换成码云 Gitee；
　③ 说找不到分支 = 码云默认分支是 master、GitHub 是 main，填对；
　④ 409 = 刚提交完服务端还没同步好，等两三秒再点一次；⑤ 400 sha is missing = 云端已有这个文件，
　先「只从云端合并下来」再「立即同步」。
